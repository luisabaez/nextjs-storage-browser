## Resource Inventory

### S3 Buckets

| Resource | Environment | Name | Purpose | Status |
|----------|-------------|------|---------|--------|
| S3 | DEV | `hacienda-erp-dev` | Development file storage | Active |
| S3 | PRD | `hacienda-erp-prd` | Production file storage | Active |

**Folder Structure (all buckets):**
- `ConversionFiles/` - Converted data files
- `ConversionFileErrors/` - Files with conversion errors
- `InitialUpload/` - User uploaded files
- `InitialUploadErrors/` - Upload error files
- `TSQLFiles/` - T-SQL script files
- `DataValidation/` - Data validation files
